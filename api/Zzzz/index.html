Zzzz

Zero schema serialization for Luau.

Zzzz takes any Luau value and turns it into a compact buffer with no type declarations to write and no schema to keep in sync. It works out the shape and picks the narrowest wire representation for every value. 

local Zzzz = require(ReplicatedStorage.Zzzz)
local Zz = Zzzz.new()

local packet, instances = Zz:Serialize({
    Coins = 5000,
    Position = Vector3.new(10, 20, 30),
})

local data = Zz:Deserialize(packet, instances)

Serialize​

</>
Zzzz:Serialize(value: any) → (
buffer,
{Instance}

Serializes any supported value. Returns the packet buffer and a side array of Instances the value referred to, since Instance references cannot travel inside a buffer. 

local packet, instances = Zz:Serialize(value)

Diff​

</>
Zzzz:Diff(
baseline: any,
current: any
) → (
buffer,
{Instance}
)

Serializes only what differs from a value the receiver already holds. Writes both a patch and the full form and returns whichever is smaller, so it is never larger than a plain Serialize. 

local packet = Zz:Diff(lastSent, state)

DiffOnly​

</>
Zzzz:DiffOnly(
baseline: any,
current: any
) → (
buffer,
{Instance}
)

A patch, without encoding the full form to compare against it. Roughly twenty times faster than Diff on sparse traffic, but a patch can exceed the full form's size when most of the data changed. 

local packet = Zz:DiffOnly(lastSent, state)

Patch​

</>
Zzzz:Patch(
baseline: any,
packet: buffer,
instances: {Instance}?
) → any

Rebuilds a value from whatever Diff or DiffOnly returned. Accepts a patch or a whole packet, so the caller does not have to track which was sent. 

local state = Zz:Patch(lastSent, packet, instances)
